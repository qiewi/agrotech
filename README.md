## <a name="introduction">🚨 Introduction</a>

Agrotech is a Progressive Web App (PWA) that focuses on farm monitoring using IoT sensors and deep learning to identify plant diseases based on image.
Moreover, there is also an AI Chatbot that helps farmer to consult about their crop.

## <a name="tech-stack">⚙️ Tech Stack</a>

- NextJS
- React
- FastAPI
- OpenAI API
- IoT Sensors

## <a name="features">🔋 Features</a>

- Plant Disease Identifier
- Field Sensor and Monitoring
- AI Chatbot
- Crop Care Guidance

## <a name="quick-start">🚀 Quick Start</a>

Follow these steps to set up the project locally on your machine.

**Prerequisites**

Make sure you have the following installed on your machine:

- [Git](https://git-scm.com/)

**Cloning the Repository**

```bash
git clone https://github.com/qiewi/agrotech.git
```

**Running the Project**

```bash
using an IDE, open the cloned repo folder 
```

```bash
type 'cd frontend'
```

```bash
type 'pnpm i' in the terminal
```

```bash
back to the root folder, type 'cd backend'
```

```bash
type 'pip install -r requirements.txt' in the terminal
```

```bash
back to the root folder, type 'pnpm run dev'
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the project.
